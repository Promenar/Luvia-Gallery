# 大图修复与外部图片编辑

## 目标

在现有查看器和独立编辑页面中处理大于 4000 万像素的图片；模型推理在 FNOS 本地执行，预览不改写原图。用户可将修复结果保存为同目录副本，或选择媒体库和相对文件夹导入新文件。用户负责视觉质量验收。

## 职责与约束

- 后端负责大图分块、蒙版坐标映射、合成、模型缓存、外部图片暂存与导入接口、权限和测试；前端负责人独占 `apps/web/**`，包括移除查看器右上角多余的“完成”按钮。
- 输入和蒙版坐标均以 EXIF 方向校正后的原图为准；块带上下文，只有核心区域被合成，原始尺寸和透明通道保持不变。模型输出与缩放、跨块接缝的视觉质量由用户验收。
- 图片大小、像素与内存预算可配置；单个模型作业串行执行。模型按使用缓存并依据资源限制淘汰，显存不足时给出错误或安全释放，不能因为本机硬件而限制其他部署。
- 结果为临时预览；不覆盖原图。保存或导入使用排他创建，重名不会覆盖已有文件；仅管理员会话可写入媒体库，路径必须属于所选媒体库，拒绝目录穿越和符号链接逃逸。
- 输入文件和中间结果均保存在服务端缓存目录，按用户隔离和过期回收；无第三方上传。

## 前后端对接草案

本节是可供页面与 mock 并行开发的接口草案，最终字段以 `packages/contracts` 和后端实现为准。每个写请求带现有 CSRF 请求头。

1. `POST /api/v2/editor/uploads?name=<URL编码文件名>`：请求体为 `application/octet-stream` 图片字节。返回 `{id,name,width,height,mime,sourceUrl,expiresAt}`；`sourceUrl` 仅当前用户可访问。文件选择器、拖放和剪贴板均转换为同一上传流程。
2. `POST /api/v2/editor/jobs` 接受现有 `{mediaId,source,model,mask}`，或外部图片 `{uploadId,model,mask}`。作业查询、取消、结果预览和能力接口沿用现有接口；上传 ID 不可替换内容。
3. `POST /api/v2/editor/jobs/:id/import`：提交 `{libraryId,folder,name,operationId}`，`folder` 是所选媒体库下的相对路径，空字符串表示库根；返回 `{status,mediaId,name,folder}`。允许创建所选库内不存在的文件夹，禁止覆盖，结果已写盘但索引未完成时返回 `pending`。
4. 文件超限、类型不支持、空间不足、权限不足、过期、目标只读与无效目录均返回可展示的稳定错误码；上传和作业支持取消，关闭页面不会自动导入。

页面沿用现有组件和视觉样式，支持文件选择、拖放、粘贴、蒙版绘制、模型选择、预览对比及选择目标目录；前端不读取宿主机绝对路径。外部图片的上传和导入功能以实际接口及能力为准，不能以 mock 冒充已联通。

## SLBR 自动定位规划

自动定位单独提供检测作业和候选蒙版：本地运行 SLBR 的检测输出，映射回方向校正后的原图，先供用户预览、编辑和确认，再调用修复。检测与修复共享模型缓存和串行 GPU 队列；批处理需有队列上限、取消、逐图状态及失败重试上限。当前页面和接口不得将自动检测标为可用。大图局部检测可能漏掉小水印，需比较缩略全图、重叠分块和混合策略，记录召回与误检；不得未经确认批量覆盖或删除原图。

## 验收

- 构造超过 4000 万像素图片、方向旋转、透明通道、跨块与稀疏蒙版，验证输出尺寸、非蒙版像素、作业取消与内存上限。
- 在 FNOS 记录三模型冷启动、热调用、切换的耗时和显存；模拟无 GPU，验证串行和可恢复的容量错误。
- 上传、作业、导入按用户和媒体库授权；验证路径逃逸、符号链接、重名、只读、缓存过期及索引失败。真实原图不作删除测试。
- 核验生产 API、worker 和本地推理服务健康，保留现有缩略图与可回滚镜像；前端页面由其负责人合入后再做端到端验证。
