# SLBR 自动修复

## 目标与交互

单张图片可自动识别水印并生成预览，用户可编辑候选蒙版，保存新副本或确认覆盖原图。批量支持逐项审核和自动保存两种模式；逐项审核允许用户确认、跳过或调整，自动保存无需逐项确认。两种批量均可查看每项状态、暂停、继续和取消，批量结果保存为新副本。

覆盖功能在 Linux 服务端启用，CMYK 原图覆盖时转换为 sRGB；服务端能力接口向其他平台说明不可覆盖的原因。

## 实现边界

- 推理服务返回 SLBR 的检测蒙版，检测与修复共用模型缓存、GPU 准入和取消机制；能力接口只声明实际可用的能力。
- 检测、修复、保存的作业状态和源版本由服务端持久化。批量项目按有限并发处理，记录失败原因并限制自动重试；重启后可以恢复，不重复创建副本。
- 仅管理员可创建和管理作业，媒体路径与保存目的地沿用现有安全检查。副本同名时不覆盖；单图选择覆盖后仅刷新该媒体的缓存。
- 检测蒙版使用方向校正后的原图坐标。预览可下采样，原始检测区域与编辑操作需保留足够精度，跨块、旋转与透明图片应有回归验证。
- 单张和批量复用现有组件与视觉体系；操作状态、空检测、失败、暂停及恢复均需明确显示。

## 使用与运行

- 管理员在查看器或 `/editor` 的单图修复中选择 SLBR 自动修复；没有检出时显示提示，可以调整候选蒙版后生成预览。查看器默认保存副本，也可确认覆盖单帧 JPEG、PNG 或 WebP 原图；外部上传图片导入为副本。
- 照片页多选后创建批次，每批最多 1000 张。可选择逐张审核，或确认后自动保存有检测结果的图片；目标媒体库与相对目录在创建时指定。可在 `/editor` 的批量处理页查看、暂停、继续、取消和重试。
- 检测以 1024 像素核心块和 128 像素上下文覆盖方向校正后的图片；蒙版阈值可调。小水印与跨块特征可能漏检，误检也可能修改不需要修复的区域，尤其是全自动模式；请先用样本验证实际效果。
- 批次状态和源文件版本写入数据库，发布副本前再次校验源版本并使用稳定操作编号。停止或崩溃后继续处理；已发布副本使用原编号对账，未发布的私有暂存按身份检查后回收。每项自动尝试最多三次，正在等待有效租约不计为失败。
- 按 API 实例运行一个批次调度器，单机推理服务串行执行。待审核结果和蒙版保留至处理完成；`EDITOR_BATCH_PENDING_BYTES` 默认 2 GiB，达到预算时等待审核释放空间。`EDITOR_INFERENCE_TIMEOUT_MS` 默认 600000 毫秒，`EDITOR_MAX_IMAGE_PIXELS` 默认 1 亿像素，相关参数按设备能力调整。
- 覆盖会保留媒体 ID 和收藏等关联，推进源与缩略图版本并排队更新缩略图。用户须确认不可撤销的原文件替换；JPEG 与 WebP 会重新编码，文件系统扩展属性及硬链接关系可能变化。色彩配置与可保留的图片元数据随原文件传递，EXIF 方向按输出像素归一化。
- 覆盖遇到路径冲突时保留原文件和修复结果，并保护对应索引；后台会继续尝试恢复，页面可在解决冲突后以同一操作重试。回滚服务前须确认没有等待恢复的覆盖操作。

## 验证

- 推理层验证蒙版的方向、尺度、空结果、鉴权、取消和共享 GPU 准入；对照真实模型检查检测输出及未选区域像素。
- 服务端验证权限与源版本、三种模式、重启恢复、幂等保存、同名文件和失败次数限制；覆盖场景验证版本、缓存与原文件保护。前端验证交互、进度、队列及原有页面。
- FNOS 使用实际模型和隔离合成图验证显存、耗时及大图行为；生产保留回滚镜像并验证健康状态和入口。用户用真实图片验收画质。
